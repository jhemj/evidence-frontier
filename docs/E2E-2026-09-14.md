# 검증 범위

공개 저장소에는 합성 증거 생성기와 재현용 검사만 포함합니다. 실제 증거, 개별 사건 식별자, 원문, 상세 조사 기록과 보고서는 공개하지 않습니다.

검증 단계는 별도로 구분합니다.
- Windows Python 및 Linux 컨테이너 회귀 검사
- 합성 E01과 실제 로컬 모델의 Docker 기능 E2E
- 사전 정의한 합성 자료의 탐지·오탐·판정률 평가
- 비공개 실이미지의 새 조사: 실행 여부와 완료 여부를 별도로 기록

새 릴리스의 기능 변경과 남은 검증은 [조사 고도화](INVESTIGATION_UPGRADE.md)를 참조하세요. 이전 버전의 시험 통과는 새 버전 전체 E2E 통과를 의미하지 않습니다. Ubuntu 네이티브 호스트 설치와 일반 사건에서의 탐지 정확도는 별도 검증이 필요합니다.
