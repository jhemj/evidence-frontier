# 조사 고도화 · 2026-09-15

## 적용 내용

- 검색을 고정된 앞부분 결과에서 커서 기반 페이지로 변경. 각 호출은 64 MiB 스캔 예산과 최대 60개 관측을 사용하며, 검색 조건·원문 목록·색인 identity·계약 버전이 달라지면 커서를 거절합니다. 경로 하위 범위, 계정 문자열, 시간대가 명시된 시간 필터를 지원합니다. 시간 없는 원문은 시간 필터에서 제외한 개수를 표시합니다.
- 원본 파일의 지정 바이트 범위와 이미 보존한 원문의 범위를 별도 도구로 읽습니다. 압축 해제 좌표는 압축 원본의 좌표와 구별하고, 모든 보존 원문은 조회 전에 해시를 확인합니다. 일반 검색은 literal substring이며 정규식·Boolean 검색은 지원하지 않습니다.
- 자료군별 발견·읽기·보존·텍스트 파싱·미처리를 분리합니다. 중요 자료의 미처리 범위에서 최대 8개를 읽기 전용 보완 조회합니다. 이는 전체 공백의 자동 해소를 뜻하지 않습니다.
- 원문 중심 첫 검토 뒤 이전 평가를 공개하는 비교 검토를 수행합니다. 같은 로컬 모델의 재검토를 통계적 독립성으로 주장하지 않습니다. 같은 파일에서 파생한 관측은 같은 발생원으로 표시합니다.
- 설정·호출·실행·통신·목적·의도별 주장에 확인/유력/미확인을 각각 부여하고 인용 범위를 검사합니다. 정적 설정만으로 실행이나 통신 성공을 확정한 단계는 거절합니다. 일반 자연어 해석의 정확성을 보증하는 검증기는 아닙니다.
- 후속 검사에서 사전 지지/반증/불명 조건, 실제 결과 평가, 미평가·중복·예산 제한을 보존합니다. 최종 입력에 포함된 해당 단서의 근거만 인용할 수 있습니다.
- 기본 큐 최대 256개, 일반 설정 변경 최대 96개. 단서 판단 task 전체의 일반 모델 시도 최대 576회, 일반 도구 72회이며 generation 변경으로 사용량을 초기화하지 않습니다. 전체 task의 절대 상한은 모델 582회·도구 76회이며, 이 안에 복구용 모델 6회·도구 4회를 예약합니다. 일반 상한과 전체 상한을 함께 검사합니다. 제한 복구는 최대 3개 실패 단서, task당 1회입니다. 초과 단서는 미검토로 남습니다.
- 타임라인 등급 수는 이번에 검토를 끝낸 판단만 포함합니다. 미검토·실패·과거 미재검증을 별도로 유지하고, 시각 미확인 필터와 자료 처리 범위를 제공합니다.
- 변경 없는 화면 갱신은 작은 상태만 조회합니다. worker 진행률은 계속 조회하며, 서버 재시작과 새 기록은 전체 화면 갱신을 유발합니다.

## 검증과 재현

```sh
uv run --frozen pytest -q
python scripts/run_investigation_e2e.py --fixture hunt --model YOUR_LOCAL_MODEL
python scripts/evaluate_report.py artifacts/hunt-validation/CASE_ID.zip
```

`config/hunt-evaluation.json`은 사전 고정된 합성 자료 기준입니다. 탐지율은 미탐을 포함한 전체 정답을 분모로 사용하고, 정상 미처리를 TN으로 계산하지 않습니다. 미검토·실패는 판정률 분모에 남습니다. 이 지표는 합성 내용 및 구조 검증이며 실사건 침해 탐지율이 아닙니다.

새 코드의 Windows Python 및 Linux 컨테이너 회귀 검사 130개가 각각 통과했습니다. GitHub의 Windows/Ubuntu 회귀 검사와 Ubuntu Docker 빌드·기동·HTTP smoke도 공개 직전 버전에서 통과했습니다. 공개 코드 검토와 수정 이후 비공개 실이미지를 새 case/run으로 시작하며, 완료 전에는 새 E2E 통과로 보고하지 않습니다. Ubuntu 사용자 호스트의 대용량 실이미지, 디스크 부족 상태의 실제 Docker 서비스, 모델 장애 상태의 새 전체 E2E는 미검증입니다. 기존 오류 처리·재시작·실행 불명 보존은 회귀 검사와 별도로 구분합니다.

## 공개 소스 범위

공개 저장소는 검토된 소스 스냅샷에서 시작합니다. 비공개 개발 이력, 실제 증거, 사건 DB, 보고서, 인증 정보, 개인별 환경 파일은 게시하지 않습니다. 모델과 도구는 실행 시 사용자가 설치하고 설정하며, 고정된 Python 의존성과 Docker 빌드·Windows/Ubuntu 설치 스크립트를 제공합니다.
