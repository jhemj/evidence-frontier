# 읽기 전용 조사 화면 계약

`ui/observer/`는 조사 원장을 별도 스냅샷으로 읽는 관찰 화면이다. 정적 안내자, 질문·주장·검사·원문 상세, 사건 시간축과 보고서 연결을 제공한다. 화면 열기·선택·필터·재접속은 새 모델 호출이나 조사 명령을 만들지 않는다. UI가 조사 엔진의 의미 정확도나 효율을 개선했다는 뜻은 아니다.

## 공통 스냅샷

`scripts/observer_snapshot.py`는 SQLite를 읽기 전용 트랜잭션으로 읽는다. `workbench/observer_view.py`는 새로운 판단 없이 표시 계약을 조립한다. 사건·차수·모드·원장 위치와 객체별 버전 참조를 검증하며, 정정·누락·역순 수신 시 낡은 판단을 최신으로 표시하지 않는다. 원문·파일명·모델 출력은 비신뢰 표시 데이터다.

작업 상태의 확인 시점과 판단 기준 시점은 다르다. 실제 작업 참조가 없으면 실행 중이라고 만들지 않는다. 다음 검사는 후보·예정·실행·자료 필요를 구별하며, 검사 성공을 가설 입증으로 승격하지 않는다. UI에는 검사 목적과 근거에 기반한 조사 설명을 제공하고 모델 내부 사고 전문을 전달하지 않는다.

## 시간과 보고서

행위 시각, 기록 시각, 파일 시각 및 추정 근거를 구별한다. 절대 시각으로 비교할 근거가 없는 항목은 별도 영역에 보존한다. 시간순 배치는 인과관계를 뜻하지 않는다. 같은 원본·같은 행위·같은 물리 결과 재사용은 서로 다른 관계다.

보고서가 없으면 미생성으로 표시한다. 기존 보고서는 사용한 역사적 판단 묶음을 유지하고 정정 영향은 별도 표시한다. 모델에 제시되지 않은 범위와 불확실성을 숨기지 않는다.

## 배포와 표시 안전

`scripts/serve_observer.py`는 loopback에 바인딩하고 고정 GET/HEAD 경로만 제공한다. 원장, 동결 조사 코드, 스케줄러를 변경하지 않는다. 표시에는 안전한 DOM 삽입, CSP 및 외부 자원 차단을 사용하며 증거 URL 미리보기나 명령 실행 링크를 만들지 않는다.

Live2D SDK나 모델은 포함하지 않는다. 향후 승인된 렌더러는 표시 상태만 받고 실패 시 정적 안내자로 전환한다. 효과가 비활성화돼도 현재 작업·실패·정정·원문·보고서에 접근할 수 있어야 한다. 모션 감소와 숨김 탭 정지를 지원한다.

## 다음 UI 검토 방향

중앙 안내자와 짧은 조사 설명, 핵심 사건 시간축, 선택 시 설명과 판단 이유를 보여주는 구성을 검토한다. 내부 식별자·해시·스키마·디버그 정보는 세부 보기로 옮기되, 실패·자료 부족·정정·판단의 한계는 숨기지 않는다. 이는 설계 방향이며 현재 UI에 모두 구현됐다고 주장하지 않는다.
