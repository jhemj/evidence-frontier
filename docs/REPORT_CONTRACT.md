# 배포 보고서 계약 — ko-dual-report-1

## 요구 출처와 적용 범위

보고서 양식은 **짧은 임원용 결과 보고와 이해하기 쉬운 분석가용 상세**를 분리하면서 사실·등급·근거·한계를 일치시킨다. 실제 사건 문서와 비공개 대화의 링크·식별자는 공개 계약 문서에 포함하지 않는다. 프로그램의 공개 배포는 사건 자료의 외부 공유 권한을 의미하지 않는다.

## 출력과 내용 계약

| 파일 | 용도 | 내용 선택 |
|---|---|---|
| executive.html / executive.docx | 임원용, A4 2–3쪽 목표 | 핵심 판단, 관련 원문 시각, 대상/영향, 주요 경과, 실제 대응 미등록 표시, 권고, 막힌 결론/필요 자료 |
| analyst.html / analyst.docx | 분석가용, 길이 제한 없음 | 전체 현재 판단, 관측 사실/의미/단계/대안/검사/공백/위치, 종합 가설, 세션 후보, 타임라인, 이력, 근거·지표·영수증 부록 |
| report.json / report.zip | 원문 포함 제한 배포 | 전체 스냅샷, 과거 이력, 원문 매핑/해시, 조사 산출물. 배포용 Word 다운로드와 분리 |

`report_views.project`가 원장 사본을 마스킹한 후 한 번 선택한 블록을 Jinja HTML과 python-docx가 소비한다. HTML을 임의 Word 변환기에 보내지 않고, 모델도 재호출하지 않는다. `finding_map`과 `reader_counts`는 원본 스냅샷 JSON에도 저장한다.

기존 ReportDocument 1.1의 `id/generated_at/case/evidence/coverage/limitations/judgments/automatic_findings/claims/observations/lineage/hypotheses/tool_receipts`는 유지한다. 1.2는 현재·과거 검토 단위, 검사 원장, 세션 후보, 최종 가설, 완료 범위, 필요 자료, 실패 진단과 읽기 양식 계약을 더한다. Jinja autoescape를 유지하고 증거 문자열에 `safe` 필터, 외부 스크립트·폰트·CDN을 사용하지 않는다. SHA-256은 변조 탐지이며 전자서명·공증이나 자연어 분석의 정확도 보증이 아니다.

- F-001 등의 동일 번호를 두 읽기 방식에서 공유한다. 과거 미재검증·반증됨·미검토·실패·자료 미확보 항목은 현재 3등급 항목 수에서 제외한다.
- 숫자는 **판단 항목 수**이며 침해 사건·서버·파일 수가 아니다. 가설 종합을 단서 판단에 중복 합산하지 않는다.
- 시각은 원문의 시간대와 `time_basis`를 유지한다. 시간대 없는 값을 한국 시각으로 임의 변환하지 않는다. 인증·파일 설정·실행·연결·목적 달성을 구분한다.
- 진행 중 문서는 기준시각 현재의 중간 스냅샷이다. Word 파일 생성이나 해시 성공은 조사 완료·무침해를 뜻하지 않는다.
- 분석가용 저장 출력은 200개 인용 제한이 없다. 근거 부록은 이미지·파티션·경로·inode·좌표 기준·행/바이트·원문 해시·영수증을 보존한다.
- 복구·차단 등 실제 수행 이력이 없는 경우 `수행 여부 미등록`으로 표시한다. 권고를 이미 수행한 대응으로 쓰지 않는다.
- 중요 한계는 쪽수 목표 때문에 삭제하지 않는다. 대형 사건은 임원용도 3쪽을 초과할 수 있다.

## 배포·민감정보·불변성

`report_redaction`은 명시된 credential 키, password/token 대입문, Bearer/Basic, URL 인증값, sshpass/curl 인자, 쿠키 헤더, 개인키 블록과 일부 토큰 형식을 찾고 다른 문장에 재등장한 동일값도 삭제한다. 원장은 변경하지 않는다. 무표식 비밀값을 완전 탐지하는 DLP가 아니며, 외부 배포는 기관 정책에 따른 최종 검토가 필요하다.

원문 ZIP은 의도적으로 원문을 포함하므로 UI에 `원문 포함 근거 패키지 · 제한 배포`로 구분한다. 기본 Word 버튼은 ZIP을 같이 내려받지 않는다. 기존 형식 ZIP은 소급 수정하지 않는다.

4개 배포 파일 모두 생성·Word XML/관계 검증 후에만 보고서 완료 기록을 등록한다. 생성 중 근거 리비전 변경 시 등록을 거부한다. 저장된 HTML/Word 조회는 해시를 검증하며 추가 분석이나 재생성을 하지 않는다. 보기 전환은 같은 report_id를 사용한다.

## 검증과 재현

- `tests/test_dual_reports.py`: 내용·등급·번호 공유, 민감값/동일값 재인용/메타데이터 삭제, 외부 리소스 배제, 이력 분리, 시간대, 원자적 생성, 저장본 불변성·변조 거부, 공유 모델 예산.
- `tests/test_report_snapshot.py`: 보고서 생성 중 조회/메시지 응답, 근거 변경 거부, 동시 생성, 원문 해시 검증.
- `tests/test_autonomous_review.py`: 200개 초과 인용, 원문 분할, 미평가 검사, 종합/실패/상태 구분.
- `scripts/report_sample.py --format docx`와 `--format html`: 개인정보가 없는 합성 예제. 문서 작업은 Codex 번들 Python/LibreOffice로 렌더링하고 모든 페이지 PNG를 확인한다. 실제 사례의 분석 정확도를 증명하는 테스트가 아니다.

대표 예제 출력은 `artifacts/report-contract-sample/`에 저장한다. 구조·스냅샷 테스트의 통과, Word 시각 검증, 실제 로컬 모델 조사 테스트는 각각 별개의 검증 결과로 기록한다.
