## 채택 구조

`preflight → plan → dispatch → await_jobs → ingest_validate → assess → challenge → stop_gate → publish`

LangGraph와 SQLite checkpointer가 다음 실행 단계를 저장한다. 각 controller tick은 한 노드를 진행하고 동기 checkpoint를 남긴다. 그래프에는 사건 원문 대신 run/plan/job/result 참조만 저장한다. 긴 도구 실행은 별도 worker job에서 수행하고 HTTP 요청은 제출·조회로 분리한다.

필수 내용 수집과 결정적 설정/호출/audit 연결 분석은 모델 선택과 관계없이 실행한다. 10개 항목은 조사 영역이며 구체적 주장은 근거 ID와 경쟁 설명을 포함하는 별도 후보다. AI가 추가 검색·원문 재읽기·정적 검사·TAR 목록 검사를 선택한다. 상위 후보에는 원문 재확인과 기록 검색을 수행하고, 그 영수증을 포함해 로컬 모델이 경쟁 설명을 검토한다. 재읽기를 독립 발생원 검증으로 부르지 않는다.

## 복구 계약

- 요청은 재전달될 수 있다. 동일 논리 작업의 결과는 한 번만 채택한다.
- 실행 전 모델 호출·도구 작업을 원장에 예약한다. 재개해도 예산을 환급하지 않는다.
- 단일 worker 파일 잠금으로 중복 작업자를 막고 job/attempt/owner를 기록한다.
- 결과 envelope를 임시 파일에 쓰고 fsync·최종 이름 확정 후 현재 활성 attempt와 일치할 때 DB에서 채택한다. 파일과 DB가 단일 transaction이라는 전제는 두지 않는다.
- 재시작 시 완성된 envelope의 요청·결과 해시와 attempt가 맞으면 채택한다. 그렇지 않은 실행 중 작업은 `execution_unknown`으로 보류한다. 자동 재실행하지 않는다.
- 일시정지는 신규 제출을 막고 이미 제출된 작업을 마무리한다. 실행 상태를 확인하기 전에는 증거 연결을 해제하지 않는다.
- worker 프로세스 강제 종료 후 내부 도구를 중간부터 재개하는 기능은 없다. 확인 가능한 결과만 재사용한다.

## 결과 계약과 한계

설정 등록, 호출 기록, 프로그램 실행, 세션 성립, 목적 달성을 구분한다. 자동 조사 종료는 침해 판단 완료를 뜻하지 않는다. 모델/도구 예산 소진과 미지원 범위는 `partial` 및 종료 사유로 보존한다. AI 후보는 자동으로 분석가 승인 상태가 되지 않는다.

보고서 JSON, 타임라인, 지표 후보, 원문 매핑, 파일 해시와 결과 revision을 함께 저장한다. 사용자 보고서 양식은 렌더러에서 추후 교체한다.

Linux 증거를 Windows Docker Desktop 또는 Ubuntu Docker Engine에서 처리하는 구조다. Windows 증거 파서 지원과 호스트 지원을 혼동하지 않는다. journal·패킷·메모리·삭제/미할당 복구·아카이브 전체 내용 등 미지원 영역은 범위 원장에 명시한다. 전체 이미지 또는 전체 침해행위를 분석했다고 표시하지 않는다.

로컬 실행은 설치된 모델을 사용하며 모델 가중치는 배포물에 포함하지 않는다. 호스트 Ollama의 클라우드 기능은 운영자가 `OLLAMA_NO_CLOUD=1`로 비활성화해야 한다. 외부 모델로 자동 대체하지 않는다. 로컬 GPU 실행 확인과 호스트 전체 인터넷 차단 검증은 서로 다른 시험이다.


## 사용자 후속 요구 반영: 승인 없이 AI 최종 판단

2026-09-14 후속 지시에 따라 분석가 승인·제외를 기본 작업 흐름에서 제거했다. 기존 LangGraph의 조사·도구·대안 검토가 끝나면 별도 영속 단계 `ai_judgment`가 로컬 AI로 중간 해석을 통합한다. 확인·유력·미확인 결과와 근거·이유·대안·남은 검사를 저장하고 보고서를 자동 생성한다. 유력한 판단도 표시하며 완전한 증명만을 요구하지 않는다. 이것은 기존 ChatGPT 합의 이후 사용자가 수정한 제품 요구다.

AI 최종 판단은 원문 관측을 수정하거나 분석가가 승인한 것처럼 기록하지 않는다. 별도 불변 판단 기록과 모델 영수증을 남긴다. 최대 2회 시도 예산과 입력 근거 ID를 호출 전에 저장하고, 저장된 결과가 있으면 재생성하지 않는다. 확인·유력 판단에 없는 근거를 인용하거나 근거 없이 단정하면 채택하지 않는다. 근거 ID 검증이 자연어 해석 전체의 정확도를 증명하는 것은 아니다.
