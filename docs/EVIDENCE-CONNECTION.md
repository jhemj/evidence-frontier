# 증거 연결과 연결 해제

증거 카드의 **연결 해제**를 누르면 해당 사건에서 새 조사 작업, AI 근거 팩, 새 보고서의 대상에서 제외합니다. 파일 삭제나 마운트 해제 명령은 실행하지 않습니다. 원본, 기존 관측, 작업 결과, 감사 기록 및 이미 저장된 보고서는 보존합니다. 근거 탭은 과거 조사 기록도 계속 보여줍니다.

해제한 증거는 접힌 목록에서 **다시 연결**할 수 있습니다. 기존 ID와 조사 결과를 유지하며, 완료한 작업을 자동으로 반복하지 않습니다. 아직 실행하지 않은 작업은 조사를 시작하면 이어서 실행합니다. 재연결 시 파일 구성이 바뀌었거나 원본 폴더에 접근할 수 없으면 거부합니다.

조사 중에는 먼저 일시정지해야 합니다. 일시정지는 다음 작업부터 적용되므로, 이미 진행 중인 원본 읽기가 끝나기 전까지 해제 버튼은 잠깁니다. 진행 중인 AI 요청 또는 종료가 확인되지 않은 OpenRelik 작업도 연결 변경을 막습니다.

E01~E99 숫자형 분할 이미지는 E01 하나로 선택합니다. 등록 시 세그먼트 개수, 합계 크기와 전체 세그먼트의 크기·수정 시간 서명을 저장합니다. 모든 세그먼트의 SHA-256과 `ewfverify -d sha256` 결과는 별도로 검증합니다. 통계 서명은 내용 해시를 대신하지 않습니다.

XFS 이미지에서 기본 TSK 파일 목록 읽기가 불가능하면 고정된 `dissect.xfs` 파서가 제한된 파일 메타데이터를 수집합니다. 최대 5,000개 항목, 15분, 출력 32MiB로 제한하며 삭제된 inode, 미할당 영역, swap과 예산 밖 범위는 미확인입니다. 수집 기록은 보존하되 조사 범위는 `partial`로 표시해 완료로 계산하지 않습니다. 이 범위에만 의존하는 주장도 승인할 수 없습니다.

Docker 실행은 Windows Docker Desktop의 Linux 컨테이너와 Ubuntu Docker Engine에서 같은 워커를 사용합니다. 원본 폴더는 `.env`의 `EVIDENCE_PATH`로 지정하며 읽기 전용으로 바인드합니다. 실제 경로, 증거, 테스트 보고서는 Git 저장소에 포함하지 않습니다.
